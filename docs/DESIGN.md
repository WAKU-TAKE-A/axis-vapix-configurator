# 設計メモ — axis-vapix-configurator

## 目的

サブネットが異なる Axis ネットワークカメラへ、自分の PC の IP アドレスを変更せずに、
共通設定を一括で適用する。従来は「自分の IP を一時的に変える → カメラを変更する →
自分の IP を戻す」という手作業を台ごとに行っており、それを置き換える。

## 対象変更

- Hz（電源周波数 50 / 60）
- IP アドレス（マスク／ゲートウェイは任意）
- パスワード
- NTP 参照先の指定、またはマニュアル時刻への切り替え
- IP 保持の初期化（Restore、`--restore`、単独実行専用）

AoA（AXIS Object Analytics）の無効化は対象外とした（2026-11-21 決定）。

## 引数規則

- 対象は `--ip` で複数指定し、その個数が N になる。
- 各値系オプション（`--user` / `--pass` / `--hz` / `--new-ip` / `--new-mask` /
  `--new-gateway` / `--new-pass` / `--ntp`）は次の規則で展開する。
  - 1 個 → 全台共通
  - N 個 → 台別（`--ip` と同じ並び順に対応）
  - 未指定 → その処理をしない
  - それ以外の個数 → エラー
- IP 形式、Hz の値（50 / 60 のみ）、新 IP 同士の重複、`--restore` の併用禁止など、
  すべての検証を **1 台も触る前に** 終える。検証で落ちたら何も変更しない。

## 変更の送り方

- 変更同士は束ねない。変更ごとに個別のリクエストを送る
  （失敗した変更がどれか結果にそのまま残るようにするため）。
- 例外は IP 変更の中身だけ：IP／マスク／ゲートウェイは途中で接続が切れると
  中途半端になるため、1 つの変更として 1 回のリクエストで同時に送る。
- 実行順は Hz → NTP → パスワード → IP 変更（最後。送った時点で旧 IP では切れるため）。
  1 台が失敗しても次の台へ進み、最後に台ごとの成否を集計する。

## 初期化（--restore）は単独実行専用

`--restore` は他の変更オプションとの併用をエラーにする。

理由：`factorydefault.cgi`（Web 画面の Restore 相当）が保持するのは
ブート方式・静的 IP・デフォルトルーター・サブネットマスク・ブロードキャスト・
システム時刻・IEEE 802.1X 等のみで、**ユーザー／パスワードは保持されない**
（Axis 公式文書で確認済み）。初期化後は「管理者アカウント無し」の状態に戻るため、
他の変更と混ぜるとアクセスできなくなる。初期化と設定投入は別々に2回実行する運用とする。

## TemporaryIP

自分の IP を変えずに別サブネットのカメラへ届くようにするための仕組み（Windows 専用）。

- 対象 IP:80 への TCP 接続で到達判定し、届く対象には何もしない。
- 到達できない対象は /24 ネットワーク（第3オクテットまで）単位でグループ化し、
  グループごとに一時 IP を 1 つ追加して全台処理し、`finally` で必ず削除する。
  例外・途中終了でも削除が走るようにする。
- 候補 IP は .250 から探す（.250–.254、次に .249–.240）。
  コンフリクト判定は次の組み合わせで行う。
  1. 事前確認：対象カメラ群・自 PC の既存 IP と重ならない、ping 応答なし、ARP テーブルに無い
  2. 追加後確認：Windows の重複検出の結果を見て、`Get-NetIPAddress` の
     AddressState が `Preferred` になること。`Duplicate` なら削除して次候補へ
- 追加した一時 IP は状態ファイル（`.axis_vapix_temporary_ip.json`）に記録し、
  起動時に前回の残存があればまず掃除してから始める（強制終了対策）。
- 追加には管理者権限が必要。非管理者なら、その時点で分かりやすいエラーにする。
- Windows 以外では一時 IP を追加できないため、到達できない対象はエラーとして報告し、
  到達できる対象だけを処理する。

## パラメータ名の発見

VAPIX のパラメータ名は機種・世代で差があるため、固定名を決め打ちせず、
実行時に `param.cgi?action=list` の全件リストから候補パターン（正規表現）で
特定することを基本とする。

- IP 系：`Network.IPAddress`、`Network.*.IPAddress`（SubnetMask / DefaultRouter も同様）
- 時刻系：`Time.NTP.Server`、`Time.SyncSource`（値 NTP / None / PC）は公式確認済み
- Hz：名前が Frequency を含み現在値が 50 / 60 のもの、または名前に
  PowerLine / Mains を含むものを候補とし、一意に決まらなければ失敗として
  候補一覧を報告する

### 要実機検証

- **Hz のパラメータ名特定**：候補パターンで実機の一覧から一意に決まるか未確認。
- **date.cgi による手動時刻セット**：マニュアル切替時に
  `/axis-cgi/admin/date.cgi?action=set&...` で PC のローカル時刻を送る方式は未検証。

## 単一ファイル方針

- 本体は `axis_vapix_configurator.py` の単一ファイルとし、Python 標準ライブラリのみで
  動かす（exe 化・配布を簡単にするため）。
- 将来の変更追加は「ステップ関数 1 個＋順序定義への登録 1 行」で足せる構造にする。
- コード以外のデータ（対象リスト等）はファイルに埋め込まず、コマンドライン引数で渡す。
- バージョンは 4 桁（初期 0.9.0.0）。`app_base_dir()` でスクリプト／exe のある
  フォルダを基準にし、ログと状態ファイルはそこに置く。
